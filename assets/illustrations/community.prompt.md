# Иллюстрация сообщества

Создана встроенным инструментом image_gen 16 октября 2026 года. Оригинал сохранён в каталоге generated_images; для сайта подготовлен WebP с прозрачностью без изменения композиции.

## Запрос

Создай одну законченную авторскую редакционную иллюстрацию для сайта Space Protocol, для свободного места под заголовком «Место для людей. Правила — ваши.». Широкая горизонтальная композиция примерно 2:1, прозрачный фон. Тёплый спокойный образ небольшого независимого сообщества: четыре выразительных, но очень упрощённых взрослых персонажа общаются и обустраивают общее уютное место вокруг небольшого собственного сервера, похожего на аккуратную тёмную башенку с двумя секциями и маленькой золотистой искрой. Один человек сидит с ноутбуком, двое обсуждают что-то рядом, ещё один несёт горшок с растением. Несколько низких арок и мягких геометрических форм лишь намекают на пространство, не заполняют фон. Центр — небольшая общая светлая круглая площадка, ощущение близости, самостоятельности и совместного творчества. Стиль дорогой современной печатной иллюстрации: лаконичные силуэты, округлые формы, тонкие живые линии и едва заметная бумажная фактура. Узкая палитра: почти чёрный угольный #202320, приглушённый золотистый #c8af70, оливковый #7b8067, кремовый #eee7cf и совсем немного пыльной терракоты. Основной фон сайта кремовый #eee7cf, поэтому изображение должно мягко ложиться на него, без белого прямоугольника, без рамки, без тяжёлой тени. Композиция собранная и легко читается при ширине 450 пикселей. Достаточные прозрачные поля по краям, без обрезанных деталей. Никакого текста, букв, цифр, подписей, интерфейсов, значков замка, облаков, технических схем, водяных знаков или излишней мелкой детализации.
