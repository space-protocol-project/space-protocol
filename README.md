# Space Protocol — промостраница

Публичная статическая промостраница проекта. Стиль: чёрный и кремовый, выбранный логотип «Живая искра». Возможности прототипа и будущие этапы разделены. HTML/CSS без сборки, внешних зависимостей и аналитики.

Публикация: GitHub Pages из корня ветки gh-pages. API и основное Flutter-приложение этой страницей не обслуживаются.

Шрифты размещены локально: Nunito (заголовки), Nunito Sans (текст и кнопки), JetBrains Mono (технические подписи). Источники Google Fonts и SIL OFL сохранены в assets/fonts/.

Галерея обновлена 14 октября 2026 для v0.2.2: 10 актуальных Flutter-снимков — сводка, чат, настройки, восстановление, каналы, участники, приглашения, устройства, домашний сервер и сопряжение. Снимки получены из текущих виджетов с демонстрационными данными; формы управления сняты в изолированной тестовой оболочке.

Кнопки Windows/macOS/Linux ведут на releases/latest/download в space-app; ссылка SHA256SUMS.txt и описание выпуска также следуют за последней версией. Страница сохраняет ограничения экспериментального выпуска и платформ.
