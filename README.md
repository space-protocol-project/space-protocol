# Space Protocol — промостраница

Публичная статическая промостраница проекта. Стиль: чёрный и кремовый, выбранный логотип «Живая искра». Возможности прототипа и будущие этапы разделены. HTML/CSS без сборки, внешних зависимостей и аналитики.

Публикация: GitHub Pages из корня ветки gh-pages. API и основное Flutter-приложение этой страницей не обслуживаются.

Шрифты размещены локально: Nunito (заголовки), Nunito Sans (текст и кнопки), JetBrains Mono (технические подписи). Источники Google Fonts и SIL OFL сохранены в assets/fonts/.

Галерея содержит шесть снимков основных экранов Windows и Android из Release-виджетов с демонстрационными данными. Нажатие открывает увеличенный снимок; подписи переводятся вместе со страницей.

Кнопки Windows/macOS/Linux/Android ведут на releases/latest/download в space-app; ссылка SHA256SUMS.txt и описание выпуска также следуют за последней версией. Страница сохраняет ограничения экспериментального выпуска и платформ.


Выбор языка: русский, английский и упрощённый китайский. По умолчанию используется
первый поддерживаемый язык из navigator.languages, иначе английский. Ручной выбор
сохраняется в localStorage; «Автоматически» удаляет это предпочтение. Если хранилище
запрещено, переключение работает в текущей вкладке. Внешние службы перевода не используются.
Тексты и подписи — в translations.mjs; поведение — в language.mjs. Без JavaScript
сохраняется русская HTML-версия. Скриншоты приложения не переводятся, их подписи переводятся.

Проверки: node --test language.test.mjs, node --check screen-demo.js, git diff --check.
В браузере проверены все три языка, перезагрузка с сохранённым выбором, автоматический
режим, увеличенная галерея и отсутствие горизонтального переполнения при фактической
ширине 320/390/1280 CSS-пикселей. В браузере тестирования включён масштаб 150%,
поэтому размеры области проверялись по innerWidth, а не только по параметрам окна.
