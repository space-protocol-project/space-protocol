# Space Protocol — промостраница

Публичная статическая промостраница проекта. Стиль: чёрный и кремовый, выбранный логотип «Живая искра». Возможности прототипа и будущие этапы разделены. HTML/CSS без сборки, внешних зависимостей и аналитики.

Публикация: GitHub Pages из корня ветки gh-pages. API и основное Flutter-приложение этой страницей не обслуживаются.

Шрифты размещены локально: Nunito (заголовки), Nunito Sans (текст и кнопки), JetBrains Mono (технические подписи). Источники Google Fonts и SIL OFL сохранены в assets/fonts/.

Галерея содержит шесть снимков основных экранов Windows и Android из Release-виджетов с демонстрационными данными. Нажатие открывает увеличенный снимок; подписи переводятся вместе со страницей.

Кнопки Windows/macOS/Linux/Android ведут на releases/latest/download в space-app; ссылка SHA256SUMS.txt и описание выпуска также следуют за последней версией. Страница сохраняет ограничения экспериментального выпуска и платформ.


Выбор языка: русский, упрощённый китайский и английский. Среди языков navigator.languages
автоматический выбор использует приоритет ru → zh → en; если совпадений нет — английский. Ручной выбор
сохраняется в localStorage; «Автоматически» удаляет это предпочтение. Если хранилище
запрещено, переключение работает в текущей вкладке. Внешние службы перевода не используются.
Тексты и подписи — в translations.mjs; поведение — в language.mjs. Без JavaScript
сохраняется русская HTML-версия. Скриншоты приложения не переводятся, их подписи переводятся.

Проверки: node --test language.test.mjs, node --check screen-demo.js, git diff --check.
Фон первого экрана: `hero-scenes.mjs` рисует редкие метеоры и кометы, спутник/телескоп,
астероиды и небольшую планету с луной в палитре сайта. Объекты разделены на слои
перед логотипом и за ним; текст расположен выше. Изображения из референсов не копируются.
Холсты ограничены DPR 1.5 и 30 кадрами/с; при скрытой вкладке или уходе первого экрана
из видимости цикл останавливается. При `prefers-reduced-motion` остаётся статичная сцена.
Дополнительная проверка: `node --test hero-scenes.test.mjs`.
В браузере проверены все три языка, перезагрузка с сохранённым выбором, автоматический
режим, увеличенная галерея и отсутствие горизонтального переполнения при фактической
ширине 320/390/1280 CSS-пикселей. В браузере тестирования включён масштаб 150%,
поэтому размеры области проверялись по innerWidth, а не только по параметрам окна.

Секция возможностей использует пять мини-сцен: каналы, файл в переписке, приглашение, закрытая группа и устройства. Подробности раскрываются через нативные details. На телефоне файл занимает полную строку, аватары и приглашение — ровную сетку 2×2. Анимации однократные при наведении/фокусе, без постоянных циклов. При предпочтении уменьшенного движения они отключены. Оформление секции — в features.css; сцены демонстрационные.

Ориентир по диску размещён рядом с созданием пространства: от 2 ГБ свободно, предпочтительно 5 ГБ для небольшого нового пространства без будущих вложений. Это рекомендация, а не проверенный жёсткий минимум. На 18.10.2026 манифест Windows runtime v0.6.0 сообщает 205 783 827 байт после распаковки (196,3 МиБ), ZIP — 71 880 479 байт. Установленное приложение Windows локально занимает 50,4 МиБ. База, журналы, загрузка ZIP, предыдущий runtime и копии требуют дополнительного места; проверка приложения также оставляет запас 256 МиБ. Фактический размер зависит от системы и данных. Сценарий 1 ГБ данных + 3 полные копии требует примерно 4 ГБ только для данных и копий; рекомендация от 8 ГБ включает рабочий запас, но не гарантирует размер будущих данных.
Источник runtime: https://github.com/space-protocol-project/space-server/releases/download/v0.6.0/windows-x64.json . Тексты переведены на английский и китайский.

Карточка создания пространства и раскрывающаяся инструкция имеют общую рамку и фон (`host-card`). Высота и прозрачность инструкции плавно меняются за 380 мс; закрытие также плавное. При уменьшенном движении переход отключён.
