# Размещение

Здесь появятся проверенные Docker-конфигурации и инструкции установки, обновления, backup и disaster restore.

Готового Compose пока нет. Skeleton в корневом README иллюстративен: не следует запускать его как готовый продукт. Первое рабочее размещение должно включать server/admin UI, PostgreSQL, persistent assets и HTTPS proxy.
