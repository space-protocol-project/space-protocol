# ADR-048: персональная сводка сообществ

`core.community.overview.v1` добавляет авторизованный
`CommunityOverviewService.GetCommunityOverview` через gRPC и Connect.
Запрос относится к одному forum/feed-разделу; предел по умолчанию — 6,
максимум — 20 записей в каждом списке, срок операции — 3 секунды.

Ответ содержит свежие видимые темы или публикации, непрочитанные ответы
других участников автору темы форума и счётчик ожидающих жалоб для модератора.
Фрагмент текста ограничен 240 символами Unicode. Автор и заголовок относятся
только к содержимому, разрешённому к чтению. MLS и архив исключены.

Сводка повторно проверяет сессию, grant, членство, read scope и ACL под теми же
блокировками, что поиск внутри раздела. Счётчик жалоб дополнительно требует
manage ACL и `space.manage`. Скрытые ответы исключаются из персональных
счётчиков; скрытый родитель исключает тему целиком. Жалобы на скрытые объекты
остаются задачами модератора в соответствии с действующей очередью жалоб.

Используется существующее `forum_read_state`; новых таблиц нет. У публикаций
ленты не заявляется поддержка непрочитанного. При открытии найденного ответа
клиент использует его sequence в обычном RPC темы. Открытие и дальнейшие
действия заново авторизуются сервером.

Клиент собирает результаты разных пространств в Cubit/Freezed, ограничивает
параллельность четырьмя разделами и обновляет данные только на видимой сводке.
Поколение запросов и повторная проверка каталога исключают поздние ответы
после отзыва прав, отключения или смены источника. Отказ конкретного раздела
удаляет его старые данные, сохраняя успешные результаты других разделов.
Для старого сервера показывается необходимость обновления, без выдачи
неподдерживаемого RPC или ложного сообщения об отсутствии событий.

Пара v0.7.19 / runtime v0.7.15 остаётся опубликованной базой. Новые сводка
и поиск относятся к следующему совместимому выпуску; схема исходников 32.
