# ADR-031: Иконка пространства

Статус: серверный API опубликован в v0.2.0, 12 октября 2026 года; клиент доступен в main.

ServerIcon содержит preset, media_type и data. Настройки и запрос обновления получают поле icon 6, manifest — icon 5, WatchChannelsResponse — icon 6. Иконка публична; менять её могут owner/admin с разрешением управления и актуальной revision. Старый запрос без icon сохраняет текущую.

Миграция 011 добавляет preset orbit и пустой файл. Варианты: orbit, planet, leaf, star, bolt, rocket. Файл — PNG или SVG до 8192 байт, что сохраняет лимит RPC 16 КиБ с JSON/base64. PNG проверяется декодером с ограничением 256×256; приложение уменьшает исходник до 64/48/32. SVG проверяется XML-парсером: базовые геометрические теги/атрибуты, предел токенов и глубины, без script/image/href/style/DOCTYPE/внешних URL. Клиент также проверяет SVG перед показом.

Manifest передаёт иконку новым участникам и публичному просмотру. WatchChannels распространяет смену уже подключённым клиентам; heartbeat не содержит icon. Иконка кэшируется по origin и сохраняется после отключения/перезапуска. Некорректная иконка даёт безопасный стандартный вариант; декор не заменяет проверку серверного ключа или сертификата.

Выпуск домашнего runtime v0.1.0 не содержит этого API. В приложении закреплён опубликованный v0.2.0; существующая установка обновляется через «Мой сервер» → «Обновить сервер». При отсутствии icon в настройках выбор файла не предлагается, показывается необходимость обновления сервера.
