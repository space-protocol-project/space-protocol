# ADR-056: личное избранное форума и ленты

Capability `core.community.favorites.v1`, `CommunityFavoriteService`, схема 39.
Поддерживаются тема, ответ, публикация и комментарий. Отметки принадлежат
principal пространства и общие для его устройств. Чужие отметки и ID владельцев
через этот API не выдаются; principal берётся только из проверенной сессии.

Сохранение требует чтения раздела и видимости объекта вместе с родителем.
Право записи, публикации или комментирования не требуется. Закрытая тема
и архивный раздел допускают личное сохранение при сохранённом праве чтения.
Снять собственную отметку можно также после скрытия объекта; текст и прежняя
видимость при этом не раскрываются. При потере доступа к разделу запрещены
все операции, включая повторы. Тип объекта должен соответствовать виду раздела.

`GetCommunityFavoriteStates` принимает 1–50 уникальных ссылок; неизвестные
и скрытые объекты пропускаются. `ListCommunityFavorites` возвращает только
актуальное видимое содержимое выбранного раздела: фрагмент до 240 Unicode
code points и данные для точного перехода. В БД хранятся ссылки, а не копии текста.
Список сортируется по времени сохранения в микросекундах, виду и ID; курсор
связан с principal и разделом и ограничен 1024 байтами. Каждая страница повторно
проверяет ACL. По умолчанию страница содержит 20 записей, максимум 50.
Обновление списка заново читает уже загруженное число страниц.

`SetCommunityFavorite` задаёт `saved`, ожидаемую личную ревизию объекта
(первоначально 0) и ключ повтора 1–128 UTF-8 байт. Состояние и журнал запроса
фиксируются атомарно. Канал блокируется для чтения, удерживая ACL и модерацию;
личные изменения сериализуются транзакционной блокировкой principal.
Запрос без изменения состояния не повышает ревизию и не поднимает запись.
Снятая отметка сохраняет ревизию, чтобы запоздавшее устройство не отменяло
новое решение. Текст, реакции, порядок содержимого, непрочитанное и уведомления
не меняются.

Повтор с тем же ключом и параметрами возвращает актуальное состояние и ревизию
первоначального применения. Он не повторяет старое действие после более нового
изменения. Иные параметры с прежним ключом дают AlreadyExists, устаревшая
ревизия нового запроса — Aborted. Ключи хранятся 14 дней; повтор после этого
срока не имеет гарантии распознавания. Проверка доступа предшествует повтору.
До 5000 активных отметок и 60 новых успешных операций в минуту на principal
для всех разделов и устройств. Принятый повтор не расходует бюджет.

Клиент использует Cubit/Freezed и точный повтор запроса после сетевой ошибки.
Смена пространства, личности, grant или раздела очищает состояние; запоздалые
ответы отсекаются. Активный интерфейс обновляет отметки и список каждые 10 секунд.
Переход из списка использует обычный API форума/ленты, который заново проверяет
доступ, включая доступность родителя. Прежний API или адаптер не добавляется.
