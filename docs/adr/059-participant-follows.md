# ADR-059: подписки на участников и персональная лента

`ParticipantFollowService`, capability `core.participant.follows.v1`, схема 41.
Личный список подписок общий для устройств principal внутри пространства;
чужие подписки, число подписчиков и рекомендации не выдаются. Читатель может
подписываться без права публикации. Нужны сессия, действующий grant, членство,
отсутствие блокировки, включённое общение и scope `chat.read`.

Подписка создаётся из доступного неархивного раздела ленты на активного автора
видимой публикации либо комментария с видимым родителем. На себя подписаться
нельзя. До 1000 подписок. Отмена собственной подписки доступна и после утраты
доступа к автору/разделу: она не возвращает чужой профиль или содержимое.
У недоступного автора в личном списке остаётся только уже известный ID
для отмены; имя не раскрывается. Профиль один на пространство, без переопределений.

Set принимает абсолютное состояние и общую expected_revision. Операции одного
principal сериализованы. Повтор уже установленного состояния возвращает
актуальную ревизию без изменения; устаревший запрос, меняющий состояние,
получает Aborted. Пустая отмена не создаёт строку. Ревизия меняется только
при фактическом изменении, курсор старой подписки после изменения списка
отклоняется. Клиент очищает список и предлагает обновить его.

Лента содержит публикации, репосты и цитаты подписанных авторов из всех
доступных feed-разделов. Комментарии, форум, чаты и MLS в неё не входят.
Порядок: created_at DESC, channel_id C DESC, id C DESC. Курсор привязан к
principal, виду выдачи и ревизии подписок; JSON строгий, до 1024 байт.
Страница по умолчанию 20, максимум 50; запрос ограничен тремя секундами.

На каждой странице сервер заново проверяет сессию/grant/scope, членство,
блокировку и канонические visible/read ACL. Разделы блокируются FOR SHARE
в порядке ID до выборки и LIMIT. Архив, MLS, закрытые для чтения разделы,
скрытые публикации и заблокированные авторы исключаются до пагинации.
Репост гидратируется существующим безопасным чтением оригинала в той же
транзакции; скрытый оригинал не раскрывается. Подписка не расширяет права.
Чтение ленты не меняет отметки чтения или уведомления. Переход к публикации
заново проверяет исходный раздел обычным FeedService.

Клиент использует Cubit/Freezed, ограничивает число загруженных записей,
проверяет порядок, дубли, поля и курсоры, отбрасывает запоздалые ответы при
смене пространства, principal, grant или каталога. Ошибка следующей страницы
очищает прежнюю выдачу. Сборки, генерация и тесты выполняются только в GitHub CI.
