Формат нового документа:

```text
# ADR-NNN: название
Дата:
Статус: предложено / принято / заменено
Контекст и обязательные требования:
Рассмотренные варианты:
Проверенные источники и результаты прототипов:
Решение:
Последствия и ограничения:
Критерии пересмотра:
```
