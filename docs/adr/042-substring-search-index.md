# ADR-042: индекс подстрок обычных сообщений

Статус: реализовано локально в runtime, ещё не выпущено.

## Решение

Добавить миграцию 21: частичный GIN-индекс двух- и трёхсимвольных подстрок неудалённого текста. Запросы длиной два символа используют биграммы, остальные — триграммы. После отбора кандидатов обязательна точная проверка strpos. Набор триграмм сам по себе не доказывает непрерывную подстроку. Дополнительные расширения PostgreSQL не нужны.

Нормализация Unicode закреплена в версионированной IMMUTABLE SQL-функции, не зависит от локали базы. Тела функций разбираются при создании, зависимости фиксируются объектами схемы. Изменение таблицы регистра требует новой функции и перестроения индекса миграцией; нельзя заменять семантику функции существующего индекса.

Контракт SearchContent не меняется: прежние ACL, запрет MLS, параметры, строгие границы и бюджет. База автоматически поддерживает индекс при записи, правке и удалении. Исходный текст и журнал событий сохраняются. Нормализованный текст хранится в GENERATED STORED-столбце, автоматически обновляемом PostgreSQL: повторный частый поиск не вычисляет Unicode-нормализацию для каждой строки.

## Цена

Индекс и нормализованный столбец увеличивают размер базы и стоимость записи. Добавление STORED-столбца требует физической перестройки таблицы. Миграция выполняется транзакционно при запуске; создание индекса не фоновое. Частые подстроки могут использовать прежний индекс sequence по решению планировщика. Выборочное ускорение не отменяет бюджет операции.

## Проверка

Реальная PostgreSQL: миграция готовой истории из 100 000 сообщений, план редкого запроса с GIN без Seq Scan, поиск через авторизованный RPC, все 1000 страниц, правки/удаления, новая вставка после снимка, курсор событий, отсутствие повторной записи при повторе ключа, прежняя идентичность после открытия базы. Отдельно — Unicode, запросы из двух символов, китайский текст, эмодзи, буквальные спецсимволы и ложноположительный набор грамм.

Подробные результаты и границы замера: space-server/docs/SEARCH-SCALE.md.
