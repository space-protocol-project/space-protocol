# ADR-057: общий поиск пространства

`SpaceSearchService.SearchSpace`, capability `core.space.search.v1`, ищет
буквальную подстроку в обычных сообщениях чата, темах и ответах форума,
публикациях и комментариях ленты. MLS, файлы, вложения, закрытые для чтения,
скрытые и архивные разделы в серверный поиск не входят. Существующий локальный
поиск MLS остаётся отдельным действием. Новая миграция не требуется.

Запрос после trim содержит 1–256 байт UTF-8; limit по умолчанию 20, максимум 50.
Unicode fold и 2/3-граммы совпадают с существующими индексами; один символ
ищется без gram-фильтра. SQL-метасимволы не становятся шаблонами.
Запрос ограничен тремя секундами. Результат содержит ID, название раздела,
тип, точную цель, текущую подпись автора и фрагмент до 240 Unicode code points.
Полные тексты, вложения, общие количества и сведения о недоступных разделах
не выдаются.

Каждая страница повторно проверяет сессию, grant, родительские разрешения,
scope `chat.read`, членство и блокировку. Сервер удерживает блокировки чтения
разделов в едином порядке по ID и применяет read ACL до поиска и пагинации.
Право manage не заменяет чтение и не открывает скрытый текст. Удалённые
сообщения, скрытое содержимое и скрытые родители исключаются до LIMIT.
Имя автора читается из текущего профиля, а авторство остаётся по principal ID.

Порядок: время создания в миллисекундах DESC, тип DESC, ID раздела в C-порядке
DESC, ID объекта в C-порядке DESC. Непрозрачный исключительный курсор привязан
к нормализованному запросу и principal; неизвестные поля и слишком длинные
курсоры отклоняются. Права не сохраняются в курсоре и проверяются заново.
Отзыв действует на следующем запросе; уже полученные байты не отзываются.

Клиент хранит состояние в Cubit/Freezed, проверяет поля и границы ответов,
отбрасывает дубли и зацикленные страницы. Смена пространства, личности,
grant, каталога или доступа очищает выдачу и отменяет прежние результаты.
Переход заново загружает цель через обычный авторизованный API; краткий
фрагмент не подменяет содержимое сообщения. Чтение в поиске не меняет
непрочитанное и не подтверждает уведомления.

Генерация, анализ, проверка сложности, тесты и сборки выполняются в GitHub CI.
Старый API и адаптеры не добавляются; локальный и серверный поиск не смешивают
зашифрованные и открытые данные.
