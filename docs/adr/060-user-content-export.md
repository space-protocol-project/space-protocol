# ADR-060: экспорт собственного содержимого

`UserExportService.ExportUserContent`, capability `core.user.export.v1`.
Новых таблиц нет; схема остаётся 41. Экспорт не является резервной копией.

Один запрос возвращает собственные обычные сообщения, темы, ответы, публикации
и комментарии текущего principal из доступных неархивных chat/forum/feed-разделов.
Сессия, grant, членство, блокировка, включённое общение и chat.read проверяются
канонической транзакцией общего поиска. Нужны visible/read ACL, а не право записи.
Разделы удерживаются FOR SHARE в одинаковом порядке до завершения чтения.

Скрытые/удалённые объекты, ответы скрытого родителя, MLS и чужое содержимое
исключаются до LIMIT. Чужие цитаты не гидратируются: сохраняется только repost_of.
Вложения представлены именем, MIME, размером, SHA-256 и ID; бинарные файлы не входят.
Ключи, токены, настройки сервера, личные подписки и чужие профили не экспортируются.

Можно выбрать раздел и временной интервал [after,before). Максимум 5000 записей
и 8 МиБ ответа в protobuf JSON; превышение возвращает ResourceExhausted без
частичного результата. Для больших архивов пользователь выбирает меньший период.
Запрос ограничен пятью секундами. Чтение не меняет непрочитанное и уведомления.

Клиент проверяет формат, владельца, границы, порядок, дубли и поля. Смена
пространства/личности/grant или каталога отбрасывает ответ. Сохранение происходит
явным действием пользователя в JSON UTF-8. Ранее полученные байты не отзываются
после последующего изменения ACL. Автоматической отправки архива наружу нет.
