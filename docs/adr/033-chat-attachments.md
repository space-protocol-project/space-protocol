# ADR-033: вложения в сообщениях

Статус: принято, первый срез.

Вложения передаются аутентифицированными unary ConnectRPC-запросами частями до 256 КиБ. BeginUpload резервирует весь заявленный объём; CompleteUpload сверяет размер и SHA256 и определяет MIME. Готовый файл становится доступен для скачивания после атомарной публикации сообщения. Каждая операция повторно проверяет сессию, ACL и принадлежность; чтение известно по идентификатору только участникам с текущим правом чтения канала.

Файлы и метаданные сохраняются в PostgreSQL, чтобы существующий перенос пространства включал их без отдельного файлового хранилища. Группа хранения principal_id/YYYY/MM/DD задаётся сервером по UTC. Части имеют ожидаемые смещения; повтор идентичной части допустим. Хэш исходного CreateContent включает упорядоченные идентификаторы вложений.

Общий лимит и стандартный личный лимит задаются в SpaceSettings; отдельный лимит участника — в Member. Отсутствующий индивидуальный лимит наследует стандартный. По умолчанию оба лимита 1 ГиБ, диапазон настройки 0–1 ТиБ. Ноль блокирует новые файлы, уменьшение не удаляет данные. Запросы резервирования сериализованы транзакционной блокировкой и учитывают полный размер неподключённых загрузок.

Файл не исполняется и не открывается автоматически; клиент проверяет SHA256 до сохранения через системный диалог. Превью и антивирусный обработчик остаются отдельными задачами. Неиспользованные загрузки старше суток удаляются при следующем BeginUpload. Для ограничения накладных расходов действуют пределы 10000 файлов на сервер и 20 неподключённых загрузок участника.

Контракт имени заменён [ADR-054](054-participant-profile.md); описание ниже относится к исходному выпуску вложений.

Необязательное имя хранится в membership и изменяется участником через UpdateProfile. Авторизация продолжает опираться на principal_id, непустое имя уникально в пределах сервера при назначении через UpdateProfile, но не является удостоверением личности. Уникальность проверяется после Unicode NFKC и case folding, без пробелов по краям. Пустые имена допустимы у нескольких участников.

ListChannelAssets возвращает опубликованные файлы канала всем участникам с действующим правом чтения. Поддерживает фильтр principal_id автора и страницы по 50 файлов; список авторов содержит их текущие имена. Неопубликованные файлы и вложения удалённых сообщений не выдаются. ListMyAssets по-прежнему ограничен текущим автором.

Настройка attachments_enabled (миграция 14) действует в пределах сервера и по умолчанию включена. Владелец и администратор меняют её через UpdateSettings. Manifest сообщает начальную политику, WatchChannels — изменения. Сервер проверяет разрешение при файловых операциях и публикации вложений; запрет не удаляет файлы. Клиент скрывает файловые действия, панели и метаданные вложений в представлении истории только выбранного пространства; включение возвращает доступ.
