# ADR-026: подписка на доступный каталог каналов

Дата: 10 октября 2026 года. Статус: реализовано, приёмка PostgreSQL CI продолжается.

## Контракт

ChannelService.WatchChannels — отдельная авторизованная server-streaming подписка, HTTP GET /api/v1/channels/watch. Она не зависит от выбранного чата и доступна участнику с пустым списком каналов. Начальный кадр и изменения содержат полный отфильтрованный каталог, название пространства, текущую роль и pinned server ID. Heartbeat не содержит метаданных. Снимки каталога не используют durable cursor сообщений: после переподключения всегда приходит актуальный снимок.

Сервер сравнивает только доступный этому пользователю снимок. Изменения невидимого канала не создают уведомление. Членство, token/grant и ACL проверяются каждый цикл; блокировки PostgreSQL удерживаются до ограниченной Send, поэтому отзыв не обгоняет отправку приватных метаданных. Блокировка пользователя или отзыв grant закрывают поток. Ограничение 64 потоков общее с Subscribe; один клиент обычно использует два потока.

В этом срезе сервер проверяет снимок раз в 500 ms, heartbeat раз в 15 s. Это уведомления по изменению снимка, без клиентского периодического ListChannels. Event-driven wakeup и оптимизация нагрузки остаются следующей серверной работой; моментальное обновление на commit не обещается.

## Flutter

SpaceSession проверяет server ID, роль и корректность каналов до применения снимка. ChatController независимо от подписки сообщений обновляет навигацию и права, отменяет чтение и очищает историю при потере доступа, возобновляет загрузку выбранного канала при возврате чтения. Курсоры, отметки чтения и черновики других каналов остаются изолированы.

Catalog reconnect использует bounded backoff; при disconnect, новом подключении и dispose отменяются поток и retry timer. Смена выбранного канала не отменяет каталог. На старом сервере без WatchChannels клиент сохраняет прежнее обновление через heartbeat читаемого чата; для полного поведения нужен обновлённый сервер.

## Проверки

Flutter: пустой каталог, появление канала, название, отзыв/возврат чтения, очистка истории, reconnect и отмена. PostgreSQL: отсутствие уведомления приватного канала, появление visible-only, получение чтения, роль reader, исчезновение и закрытие после logout. Native Dart/Go CI: новое имя и архив появляются через WatchChannels без ручного refresh.

Локальный Docker не запускался. Проверка физической камеры остаётся отдельным открытым пунктом и к этому транспорту не относится.
