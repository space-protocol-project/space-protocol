# P1 E06: итоговая матрица интерфейса Linux и Windows

Статус: E06 для Linux и Windows принят в GitHub CI 11 ноября 2026 года. macOS отложен по решению пользователя; этот документ не объявляет завершёнными P1 или выпуск 0.9.0.

## Проверяемый состав

Единый workflow `space-app/.github/workflows/plugin-p1-ui-matrix.yml` объединяет нативную матрицу рендерера, формы с изолированным WASM и contributions с настоящими сессиями/ACL ядра. Проверки запускаются на `ubuntu-24.04` и `windows-2025`. Версии инструментов сохранены из принятого кандидата: Flutter 3.47.8, Rust 1.99.1; серверный Go определяется закреплённым `go.mod`.

`integration_test/extensions_p1_ui_matrix_test.dart` запускает существующие проверки рендерера, форм и contributions плюс новые проверки E06 внутри нативного движка Flutter. Исходные JSON передаются из checkout через `P1_FIXTURES`, а не зависят от рабочего каталога исполняемого файла. Тот же набор отдельно запускается как widget/unit-тесты. Это два разных способа исполнения одного набора; их результаты не суммируются как независимые сценарии.

## Устранённые пробелы

- Ранее проверки клавиатуры, семантики и масштаба были только widget-тестами. Теперь они исполняются также нативно на обеих заявленных ОС.
- Добавлен полный проход формы с клавиатуры, проверка доступной ошибки с сохранением черновика и повтором, длинного варианта выбора при 300% и доступности отправки после прокрутки.
- Исправлено двойное сообщение об отказе формы: `ExtensionActions` отмечает ошибку, которую уже отображает форма, и общая панель не повторяет её. Тест требует ровно одно сообщение и одну live region; отдельный тест сохраняет отображение ошибки обычной кнопки.
- Список contributions проверяется с клавиатуры при 300%, с длинным английским fallback и доступной кнопкой возврата.
- Формы и contributions включены в один конечный workflow. Успех отдельного задания не принимается за успех всей матрицы.
- Оба стенда обновлены до серверного кандидата manifest v2 `681868587df81d07a9d3bf3cd3faf349a2c9fef5`; общие формы сверяются с протоколом `b30eb8c2c17b73051adc714120d2cf5aa19f3dd7`.
- Linux-стенд форм использует существующую ограниченную по времени установку зависимостей с резервным зеркалом и штатной проверкой подписей APT.

## Сохраняемые границы

HTTP-стенд формы использует временные роли Editor/Reader; это не сессии ядра. Настоящие сессии/ACL/PostgreSQL проверяет отдельный contributions-стенд в том же workflow; проверка payload форм в ядре сохраняется в [отчёте форм](SPACE-PLUGINS-P1-FORMS.md). Оба серверных стенда закреплены на принятом кандидате manifest v2. Полный manifest v2 и атомарность результатов/событий приняты отдельным [контрактным срезом](SPACE-PLUGINS-P1-MANIFEST-V2.md); UI-прогон проверяет совместимость с этим сервером, а не повторяет все его транзакционные сценарии.

Windows WASM-стенды используют ресурсный Job-профиль. Этот результат не доказывает сетевой запрет после успешной инициализации Winsock, дисковую границу временного профиля или полноту LPAC. Они проверены отдельным [срезом E03 Windows](SPACE-PLUGINS-P1-WINDOWS-BOUNDARY.md). macOS E03/E06 не выполнялись и остаются отложенными. Android/Web в эту настольную матрицу не входят.

После приёмки E06 и E03 Windows для текущей очереди остаётся итоговая сверка E01–E07. Рабочая интеграция оболочки, навигация, установка произвольных внешних расширений и стабильный выпуск остаются последующими этапами.

Продолжение 11 ноября: [E03 Windows — сеть после Winsock и временный профиль](SPACE-PLUGINS-P1-WINDOWS-BOUNDARY.md) принято полным CI 43064828374. Закрыты оставшиеся Windows-границы в рамках прототипа; macOS отложен. Следующий шаг — итоговая сверка E01–E07, а не выпуск 0.9.0.
