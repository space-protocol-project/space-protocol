# P1: пароль локального профиля и разблокировка расширений

Продолжение от 4 ноября 2026 года к [сессиям Flutter-приложения](SPACE-PLUGINS-P1-CLIENT-APP-SESSION.md). По выбору пользователя реализован отдельный пароль локального профиля. `SpaceApp` подключает проверяющий сервис к `LocalSessionCubit`; в разделе «Мой доступ и устройства» доступна карточка блокировки и разблокировки.

## Проверка профиля

`LocalProfileVerifier` использует существующий `PlatformKeyStorage`. Проверочная запись `space.extensions.local-profile.v1` содержит версию, случайные идентификаторы устройства и профиля, соль, результат KDF и состояние ограничения попыток. Пароль не записывается. Ошибка чтения, повреждение записи или неподтверждённая запись закрывают доступ; профиль не пересоздаётся автоматически.

Параметры версии 1: PBKDF2-HMAC-SHA256, 600 000 итераций, соль 16 случайных байт, результат 32 байта. Вычисление выполняется в отдельном isolate. Пароль обрабатывается как UTF-8 без нормализации и обрезки; принимается 12–256 Unicode code points, максимум 1024 байта, строка из одних пробельных символов отклоняется. Два результата сравниваются по всем 32 байтам. Это не заявление о гарантированном постоянном времени выполнения Dart VM.

На время операции удерживается файловая блокировка в закрытом каталоге приложения (`extensions-profile.lock`), с защитой от второго владельца в том же isolate. Повторно используется механизм владения `RegistryJournal`, но файл блокировки не содержит записей профиля или кадров журнала. Сервис рассчитан на один управляющий isolate приложения.

До вычисления KDF сохраняется номер попытки; каждая пятая попытка устанавливает задержку 30 секунд для следующих запросов. Успешная проверка сбрасывает счётчик только после подтверждённой записи. Повторное создание сервиса не сбрасывает задержку. Отмена может оставить уже сохранённую попытку или созданный профиль, но не выдаёт сессию; следующий вход читает существующее состояние. Системные часы и защищённое хранилище остаются частью доверенной среды, защиты от их отката здесь нет.

## Интерфейс и сессии

- При первом обращении окно предлагает создать и повторить пароль. Существующий профиль требует только пароль. Состояния загрузки, проверки, отказа и успеха находятся в `LocalProfileFormCubit` (`flutter_bloc`).
- Поля скрывают ввод, отключают подсказки и очищаются при отправке и закрытии. Пароль не входит в состояния Cubit. Это не гарантия обнуления всех копий неизменяемых строк в памяти Dart.
- Только результат успешной проверки возвращает привязку устройство/профиль/локальный автор в `LocalSessionCubit`. WASM-гость не выбирает эти идентификаторы. Серверная сессия не заменяет локальный пароль.
- Отмена окна, уход приложения из `resumed`, закрытие Cubit и завершение приложения запрещают позднюю разблокировку. Возврат в приложение сам по себе доступ не открывает.
- Полученная сессия использует прежний `LocalExtensionSessions`: ручная блокировка отзывает её, а подключённый локальный хост сохраняет отключённое состояние и отзывает допуски чтения. Разрешения на конкретные каталоги выдаются отдельно.
- Поддерживаются русская, английская и китайская локализации. Собственные состояния без повторяющегося копирования не требуют Freezed; привязка профиля остаётся именованным Dart record.

## Границы и следующий блок

Это один локальный профиль на установку приложения. Пока нет смены/сброса пароля, переноса профиля, выбора нескольких профилей, биометрии и автоматического восстановления забытого пароля. Пароль управляет допуском к сессии, но не шифрует существующий журнал данных расширений. Приложение не включает расширения автоматически после разблокировки.

Системное защищённое хранилище подключено через прежний адаптер без изменения его платформенной политики. Тесты этого среза не являются приёмкой настоящих Keychain, Secret Service или Windows secure storage, внешних системных диалогов и сохранности после отключения питания. Нужна отдельная нативная приёмка этих границ.

Следующий блок: нативная приёмка защищённого хранилища профиля и повторного входа после перезапуска на трёх ОС. Затем — системный выбор каталогов и файловый адаптер с проверкой отзыва во время чтения, подключённые к текущему хосту и сессии. Отдельно остаются Git-проверка пакетов, клиентский WASM-исполнитель, обслуживание журнала и рабочий интерфейс управления установками. P1 целиком не закрыт.
