# Универсальный клиент

Место приложения участников. Код ещё не создан. Первые сценарии: identity, подключение по URL, профиль сервера, чат, reconnect, recovery card и управление устройствами.

Протокольные операции проходят через SDK; экраны не зависят от внутренней реализации сервера. Выбор Flutter и первых платформ подтверждается техническим прототипом.
