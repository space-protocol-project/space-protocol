# Шрифты Space

Nunito — заголовки. Nunito Sans — текст и кнопки. JetBrains Mono — технические идентификаторы и коды. Файлы загружаются из локальных assets и не требуют сети.

Неизменённые variable TTF из официального google/fonts. Происхождение указано в SOURCES.json; SIL Open Font License сохранены рядом с файлами и включены в приложение. Лицензии зарегистрированы в Flutter LicenseRegistry.
