# Запуск отдельного прототипа

Откройте `index.html` в браузере. Для полноценного локального режима из этой папки:

```powershell
node serve.mjs
```

Если архив распакован с общей папкой `prototype`, из его корня:

```powershell
node prototype/serve.mjs
```

Адрес: http://127.0.0.1:8765. Порт используется только для статических файлов.

Прототип сохраняет демонстрационные сообщения, черновики и личные настройки в localStorage этого браузера. Не вводите настоящие секреты. Сеть сервера, identity keys, camera/microphone, file upload и приглашения не подключены. Шрифт Manrope загружается из Google Fonts; без сети используется системный шрифт.

Переключайте разделы в левой панели или нижней навигации. В «Настройках» доступны Gruvbox/личные цвета и предложение оформления пространства. В панели владельца можно изменить предложение: прежнее согласие после изменения не действует. Поиск открывается кнопкой или Ctrl/Cmd+K.

Из корня репозитория проверки:

```powershell
node --check client/design/prototype/app.js
node --check client/design/prototype/theme.js
node client/design/prototype/theme.test.mjs
```
