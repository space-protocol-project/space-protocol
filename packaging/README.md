# Установщики Space

Workflow `desktop.yml` собирает приложение и сохраняет установщики и SHA-256 в артефактах GitHub Actions на 30 дней. Он запускается вручную и при изменениях клиента в main/PR. Это пока сборки приложения, домашний сервер в них не включён.

- Windows x64: Inno Setup, установка без прав администратора в профиль пользователя, ярлык и удаление через настройки Windows. Компилятор берётся из образа GitHub runner.
- macOS: DMG с Space.app и ссылкой Applications; архитектура указана в имени файла. Подпись Apple и notarization ещё не настроены, Gatekeeper может препятствовать запуску.
- Linux x64: самораспаковывающийся `.run`, установка в `~/.local/opt/space`, команда `~/.local/bin/space`, ярлык приложения. `--extract DIR` распаковывает без установки. Нужны совместимая glibc (сборка Ubuntu 22.04), GTK 3 и libsecret; это не универсальный пакет для всех дистрибутивов.

Сборка Linux устанавливает clang, cmake, ninja-build, pkg-config, libgtk-3-dev и libsecret-1-dev только на одноразовом runner. Локальная установка зависимостей и Docker не требуются для изменения проекта.

Поддержка сборки macOS/Linux не заменяет проверки на физических системах: защищённое хранилище, камера и восстановление требуют отдельных проверок. Камера сейчас реализована для Windows.
