# Веб-панель сервера

Обязательный интерфейс владельца self-hosted установки; код ещё не создан. Собранная панель поставляется с сервером и открывается по `/admin`.

MVP: setup wizard, состояние служб, каналы и views, типы контента, участники/ACL, приглашения, квоты и retention. Включать неподдерживаемые capabilities нельзя. Интерфейс не получает Docker socket и не отправляет recovery seed на backend.
