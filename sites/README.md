# Промостраница Space Protocol

Публичная страница: https://space-protocol-project.github.io/space-protocol/

Исходники опубликованной страницы находятся в ветке gh-pages основного GitHub-репозитория. HTML/CSS и изображения автономны; сборка и сторонние зависимости не требуются. GitHub Pages публикует корень этой ветки.

Локальный checkout: space-protocol-promo-pages/. Он изолирован от main и не должен добавляться в основной репозиторий как подмодуль. Черновой checkout Sites также игнорируется: попытка отправки его исходников завершалась сетевым обрывом, публикация выполнена через GitHub Pages.

Проверены HTML-якоря, локальные файлы и HTTP 200 опубликованной страницы, CSS и изображений. 14 октября 2026 обновлены десять снимков v0.2.2 и прямые ссылки скачивания последнего выпуска для Windows/macOS/Linux. Снимки получены тестовым рендерингом Flutter с демонстрационными данными. Браузерная визуальная проверка недоступна из-за ошибки запуска среды UI-автоматизации; сами снимки проверены визуально, ресурсы и ссылки проверены отдельно. Содержимое различает возможности прототипа и будущие этапы; фиктивных отзывов или статистики нет.
