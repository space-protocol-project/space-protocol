# SDK

Место протокольных библиотек. Код ещё не создан. SDK будет выполнять discovery, проверку контрактов, authentication, actions и sync, независимо от пользовательского интерфейса.

Начальный кандидат — Dart SDK. Форматы закрепляются fixtures и независимыми проверками совместимости; платформенные vault/authenticator adapters имеют отдельные границы.
