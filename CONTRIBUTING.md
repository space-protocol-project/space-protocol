# Участие в Space Protocol

Проект пока находится на этапе проектирования. Начните с README и TODO. Перед реализацией новой подсистемы согласуйте её контракт и критерии приёмки через issue.

Небольшой PR должен объяснять проблему, изменение поведения и проверку. Изменения wire format сопровождаются схемами, fixtures и оценкой совместимости. Не добавляйте настоящие secrets, credentials и пользовательские данные.

Лицензия ещё не выбрана. До её утверждения репозиторий нельзя считать предоставленным под открытой лицензией. Правила принятия внешнего кода также нужно закрепить до начала внешних contributions.
